# Spreadsheets (XLSX) Skill

## Summary

Rules for building and editing `.xlsx` spreadsheets with `openpyxl` (`data_only=False` to preserve native template formulas, never `pandas.to_excel` on formatted templates), dynamic uppercase Excel formulas (`=SUM`, `=INDEX/MATCH`), explicit number formats, and LibreOffice recalculation audits.
